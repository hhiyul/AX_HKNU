# P5 합성 프로젝트 실행

이 디렉터리는 팀 공통 MongoDB를 변경하지 않는 독립 검증 경로입니다. 기본 Provider는 모의 응답이며 SQLite 데이터는 프로세스 메모리에만 있습니다. 프로젝트는 지속 Chat 하나를 갖고 삭제·새 대화 기능을 제공하지 않습니다. AI는 CK 변경 도구를 갖지 않으며 직접 편집은 사용자 조작입니다. 이 프로토타입의 단순한 `demo` 이용자는 인증 구현이 아니므로 localhost 이외에 공개하지 마세요.

AI가 기존 04 문서를 수정·삭제하도록 제안하거나 실행하는 경로는 사용자 요청에 따라 이번 P5 구현 범위에서 제외합니다. 문서 생성 후보는 검토 후 새 문서로 저장하며, 기존 문서의 편집·삭제는 사용자가 직접 수행합니다.

03의 추가 기록은 프로젝트마다 하나이며 검토안 준비·편집만으로 저장하지 않습니다. 사용자가 제목과 본문을 검토한 뒤 [기록 저장]을 승인하면 revision을 확인해 저장합니다. 03의 저장 기획 MD/TXT 내보내기는 여섯 CK 및 저장된 추가 기록을 포함하고, 04 문서의 TXT/MD/DOCX/PDF 내보내기와 구분합니다. 활성 첨부는 원문 다운로드가 가능하며 참고 제외는 원본 삭제가 아닙니다.

```powershell
cd backend
..\.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-p5.txt
..\.venv\Scripts\python.exe -m uvicorn app.ai.p5.server:app --host 127.0.0.1 --port 8766
```

`http://127.0.0.1:8766/`에서 합성 프로젝트를 열 수 있습니다. 서버 재시작 후에도 합성 데이터가 필요하면 실행 전에 `P5_SYNTHETIC_DB`에 새 합성 SQLite 파일 경로를 지정합니다. 실제 공통 프로젝트의 데이터 파일을 지정하지 마세요. `P5_PROVIDER=openai`와 `OPENAI_API_KEY`를 명시적으로 설정한 경우에만 실제 OpenAI 호출을 사용하며 비용이 발생합니다. 기본 테스트는 모의 Provider이고 실제 호출을 수행하지 않습니다.

04 문서의 DOCX 내보내기에는 Pandoc이, PDF에는 Pandoc과 LibreOffice가 필요합니다. 실행 파일을 PATH에 등록하거나 서버 시작 전에 `P5_PANDOC_PATH`와 `P5_SOFFICE_PATH`에 각각의 실행 파일 절대 경로를 설정하세요. Windows에서는 완료를 기다릴 수 있도록 LibreOffice의 `soffice.com`을 사용합니다. 저장된 Markdown revision을 Pandoc의 Markdown과 파이프 표 입력으로 DOCX로 바꾸고 PDF는 그 DOCX를 LibreOffice로 변환합니다. 각 요청은 별도 임시 디렉터리와 LibreOffice 프로필을 사용합니다. 변환 도구 부재·실패는 503으로 보고하며 원본 문서는 유지합니다. 한글 출력에는 환경의 한글 글꼴이 필요합니다. Pandoc 샌드박스가 허용하지 않는 외부 자료는 포함되지 않습니다.

```powershell
..\.venv\Scripts\python.exe -m pytest -q tests_unit
```

검색은 사용자가 검색 허용을 켜고 명시한 공개 검색어의 단어로 제한합니다. OpenAI 모드의 웹 검색은 그 단어만 별도 검색 요청에 넘깁니다. 실행 중 검색을 끄면 이후 도착하는 검색 결과를 사용하지 않으며, 이미 발송된 검색의 취소나 비용 면제를 뜻하지 않습니다.

물리 기본값은 합성 환경에서 파일당 5MB, UTF-8과 CP949가 모두 유효하지만 서로 다른 결과를 내는 경우 거부, 가장 최근 두 발화와 최근 AI 16k 목표를 보존, 한 실행에서 최대 6회 도구 반복입니다. 이는 팀의 실제 제공 한도나 영구 제품 정책의 확정이 아닙니다. 64k 압축의 생성 호출은 별도로 정상 3단계·단계당 실패 보완 1회까지입니다.

이 프로토타입은 임시 SQLite의 조건부 갱신과 단일 프로세스의 작업 실행을 검증합니다. 실제 팀의 인증·프로젝트/브랜드/CK owner·파일 저장소, 삭제 fence·다중 프로세스 동시성·마이그레이션 및 통합 보장은 별도입니다. 원격 결과가 미확인이거나 서버가 실행 중 재시작되면 실행 상태와 오류 코드를 기록하고 로컬 실행 잠금을 자동 해제합니다. 원래 호출의 결과·취소는 미확인으로 남으며 자동 재전송하지 않습니다. 실제 모델의 계수·스트리밍·압축·검색은 합성 사례로 검증했으며 반복 품질이나 운영 지원 보장은 아닙니다.
