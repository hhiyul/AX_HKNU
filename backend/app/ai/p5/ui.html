프로젝트 대화

컨텍스트와 토큰

입력 길이: 요청을 보내면 확인할 수 있습니다.

출력 예약과 안전 여유를 확인하는 중입니다.

이번 요청 전체 사용량: 아직 확인되지 않았습니다.

마지막 답변 모델 호출 사용량: 아직 확인되지 않았습니다.

전체 사용량은 이번 요청에서 확인된 압축·답변 생성·웹 검색 모델 호출을 합산합니다. 이전 요청과 입력 계수는 제외하며, 미확인 호출이 있으면 부분 합계입니다. 프로젝트 읽기 자체는 모델 호출이 아닙니다. 출력 예약·안전 여유는 사용량이 아니며 모델 한도는 설정 기준입니다.

검색 시 입력한 공개 검색어의 단어만 외부 검색에 사용할 수 있습니다.

문서 작성은 검토할 후보를 만듭니다. 여섯 기획 항목은 채팅이 변경하지 않습니다.
