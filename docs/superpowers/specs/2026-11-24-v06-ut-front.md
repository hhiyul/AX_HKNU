## 구조

- `src/api/`: 백엔드 호출만 모은 곳(`client.js` fetch·오류, `index.js` 도메인별 함수, `stream.js` SSE). 조원 화면으로 바꿀 때 이 폴더를 그대로 가져가면 된다.
- `src/router.js`: 해시 라우터(`#/login`, `#/home`, `#/p/:id`(작업실), `#/p/:id/docs`(저장함), `#/p/:id/docs/:docId?s=F05`, `#/p/:id/tasks`, `#/p/:id/plan`, `#/p/:id/chat`, `#/dev`).
- `src/components/Shell.jsx`: 프로토타입 작업실 틀. 탭은 작업실 · AI협업 · 일정 · 정산 · 저장함. 상품기획(`#/p/:id/plan`)은 작업실 "기본 기획" 칸에서 들어간다(프로토타입과 같음).
- `src/screens/`: 화면(Workroom 작업실, Chat, Tasks 달력, Docs 저장함, DocEditor, Plan, Home 프로젝트 고르기 전). `src/dev/DevConsole.jsx`는 예전 API 테스트 페이지(`#/dev`, 따로 불러오고 CSS는 `.dev-console` 아래로 묶음).
- `src/styles/prototype.css`: 프로토타입 CSS 원본(고치지 않는다). `src/styles/app.css`: 프로토타입에 없는 조각(항목 목차, 상태 배지, AI 후보, 할 일 제안, 안내 문구)만.
- 폰: 프로토타입의 700px 이하 규칙을 그대로 쓴다. 프로젝트 목록은 ☰로 여는 서랍, 일정은 날짜를 누르면 그날 패널이 열린다.
