## 범위

합성 이력에는 사용자가 정한 상품명 `별숲 플래너`, 고객 `대학생 자취생`, 선택 색상 `청록색`, 제외 색상 `빨간색`, 가격 상한 `17,000원`과 AI가 제안했으나 사용자가 채택하지 않은 `접이식 파우치`를 두었다. 64k 압축 조건과 최근 AI 16k 보존 조건을 만들기 위해 긴 반복 텍스트를 섞었다. 이력은 UI에서 일일이 작성하지 않고 시험 전용 DB에 직접 주입했다.
