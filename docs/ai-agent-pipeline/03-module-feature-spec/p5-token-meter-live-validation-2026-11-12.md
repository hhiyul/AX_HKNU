# P5 토큰 표시 실제 OpenAI 검증 — 2026-11-12

사용자의 유료 호출 승인에 따라 격리된 합성 SQLite 프로젝트와 `gpt-6-luna`를 사용했다. 실제 사용자·프로젝트 자료는 전송하지 않았고 웹 검색은 사용하지 않았다. 채팅 UI에서 한 요청을 보내고 완료 후 새로고침했다.

| 검증 항목 | 관찰 결과 | 근거 |
| --- | --- | --- |
| 압축 전 전체 입력 | **65,726토큰**. 64,000 기준을 초과하여 압축 시작 | 실제 입력 계수와 저장 이벤트 일치. 압축 전 숫자가 화면에 표시된 순간은 직접 관찰하지 못함 |
| 압축 후 입력 | **750토큰**. 압축 완료 후 첫 모델 호출 입력과 계수한 입력 지문 일치 | 실제 계수, 이벤트 및 계측 지문 |
| 프로젝트 읽기 후 재계수 | **991토큰**. 최종 스트리밍 요청 입력 지문과 일치 | 실제 계수, 이벤트, 브라우저 표시 및 계측 지문 |
| 스트리밍과 사용량 | 텍스트 증분 **65개**. 마지막 호출의 OpenAI 사용량은 입력 **991**, 출력 **69**, 합계 **1,060토큰** | Provider 이벤트, 저장 이벤트와 브라우저 표시가 일치. 처음 도구 호출은 입력 750·출력 42·합계 792토큰으로 별도 |
| 새로고침 | 991 입력, 출력 예약 8,000, 안전 여유 8,000, 추가 입력 여유 1,033,009와 마지막 호출 사용량 991/69/1,060 복원 | 브라우저에서 새로고침 전후 확인. 재생이 새 생성 호출을 시작하지 않음 |
| 업무 경계 | 6개 합성 CK가 모두 `UNSET`, revision 0으로 유지 | 합성 SQLite 상태 확인 |

실제 생성 호출은 총 **3회**(요약 1회, 도구 선택을 포함한 스트리밍 2회), 입력 계수 호출은 **6회**다. 요약 호출의 사용량과 요금을 계측하지 않아 전체 요청의 누적 토큰이나 청구 금액은 확인하지 못했다. UI의 사용량은 마지막 답변 모델 호출 한 건이며 압축·검색·앞선 호출은 포함하지 않는다. 합성 데이터에서 한 번 성공한 사례로, 다단계 압축, 연결 단절, 동시성, 실제 프로젝트 저장소·인증 통합의 검증을 뜻하지 않는다.

키·요약·요청 본문을 담지 않은 계측 기록은 [실행 trace](p5-token-meter-live-trace-2026-11-12.jsonl)이다. 실제 서비스의 1,050,000 모델 한도는 검증 중 동적으로 조회한 값이 아니라 기존 프로토타입 설정값이다. OpenAI 토큰 계수의 범위는 [공식 안내](https://developers.openai.com/api/docs/guides/token-counting)를 참고한다.
