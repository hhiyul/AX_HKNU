# P5 검색 요청과 문서 생성 분류 검증 — 2026-11-13

이전 검증에서 자동 구분 모드의 검색 요청에 모델이 `route_document`를 호출해 불필요한 문서 후보가 만들어졌다. 수정 후 사용자 승인에 따라 별도 합성 SQLite 프로젝트 두 개와 실제 OpenAI `gpt-6-luna`를 사용했다. 실제 프로젝트 자료는 사용하지 않았다.

| 구분 | 검증 결과 |
| --- | --- |
| 검색 꺼짐 | 이전에 오분류된 동일 문장을 자동 구분 모드에서 보냈다. 검색과 문서 생성 도구가 제공되지 않았고, 검색을 수행하지 못했다는 대화 답변이 스트리밍됐다. 문서 후보는 없었다. 초기·최종 코드에서 각각 확인했다. |
| 검색 허용 | 같은 문장으로 실제 웹 검색을 실행했다. 최종 코드에서는 URL 6개가 반환됐고, 출처 링크와 스트리밍 대화 답변이 표시됐다. 문서 생성 이벤트와 후보는 없었다. 초기 코드에서도 URL 7개와 같은 경로를 확인했다. 링크의 사실관계는 별도 검증하지 않았다. |
| 자연어 문서 생성 | 최종 코드에서 `이 텀블러의 소개 자료를 만들어 주세요`를 보냈다. 모델이 문서 생성 도구를 호출했고 검토할 문서 후보가 생성됐다. 검색은 껐다. 후보를 실제 문서로 저장하지 않았다. |
| 합성 반례 | 검색·작성법 검색·문서 생성 거부와 검색 후 명시적인 문서/소개 자료 생성 요청을 구분했다. 검색 전용 요청에 모델이 제공되지 않은 문서 도구를 호출하는 가짜 Provider를 주입해도 문서 후보 없이 대화가 완료됐다. 검색 허용·끄기 양쪽과 복합 검색·문서 생성 정상 경로를 확인했다. |

최종 코드의 `tests_unit` 116개가 통과했으며 Pandoc·LibreOffice 경로가 지정되지 않은 변환기 통합시험 1개는 건너뛰었다. 검색 라우팅 추가 반례 13개는 별도 실행해 모두 통과했다. 초기 검증과 최종 코드 검증을 합쳐 생성 10회와 별도 웹 검색 2회를 호출했고, 확인된 Provider 사용량 합계는 입력 75,246·출력 7,525·총 82,771토큰이다. 입력 계수 호출과 청구 금액은 이 합계에 포함하지 않는다.

검색 전용 판정은 제한된 표현 패턴을 사용하는 프로토타입 정책이다. 모든 언어적 표현이나 복잡한 부정·중의성을 완벽하게 분류한다는 보장은 없다. 표현이 애매할 경우 사용자는 `대화` 또는 `문서 생성` 모드를 직접 선택할 수 있다. 팀 공통 인증·저장소와의 통합은 이 검증 범위 밖이다.
