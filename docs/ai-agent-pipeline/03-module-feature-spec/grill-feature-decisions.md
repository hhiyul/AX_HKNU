GD는 이 Grill의 결정 추적 번호입니다. 질문 ID인 GQ, 사용자 정본의 D-UF, 공동 C·물리 MC 번호와 구별합니다. 이 표의 채택은 구현·시험·실서비스 검증의 완료를 뜻하지 않습니다.

GD-007에서 비교한 대가는 유지된 참고 선택을 재선택 없이 활용하는 편의와 사용자가 여전히 이용 불가라고 생각할 가능성입니다. 다음 새 요청에서 실제 재접근·사용한 결과를 구별해 안내하고, 재사용 가능과 과거 작업 자동 복구를 혼동하지 않습니다.

GD-008에서 비교한 대가는 사용자가 중단 전 얻은 내용을 활용하는 편의와 잠정 설명을 최종 판단으로 오해할 가능성입니다. 부분 내용 보존을 완료 인정·정상 저장 후보 생성으로 해석하지 않습니다.

GD-009에서는 기록을 명시적으로 남긴 사용자의 중요성 판단을 기본 내보내기 범위에 반영합니다. 질문에서 제시한 무관한 메모/오래된 내용의 동봉 가능성보다 저장된 추가 기록 전체의 포함을 택한 결정입니다. 시스템이 중요성을 다시 평가해 임의로 기록을 빼지 않습니다.

GD-010에서 비교한 대가는 중단 뒤 답변 내용이 계속 바뀌지 않는 제어 경험과 이미 수행된 호출의 유용한 결과도 현재 답변에 추가되지 않을 수 있다는 점입니다. 답변 내용 고정과 실제 실행/쓰기 결과의 확인은 구별합니다.

GD-011에서 비교한 대가는 중요한 저장 기록 전체를 포함하는 전달 약속을 유지하는 대신, 일부 자료를 읽을 수 있어도 파일 제공이 보류될 수 있다는 점입니다. 오류 상황의 별도 부분 다운로드 기능은 채택하지 않았습니다.
