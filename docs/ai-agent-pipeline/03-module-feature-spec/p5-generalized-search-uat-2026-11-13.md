# P5 일반화 검색·허용 상태 검증 — 2026-11-13

사용자가 허용한 실제 OpenAI API 호출과 별도 합성 SQLite 프로젝트를 사용했다. 실제 프로젝트 자료와 키는 검증 기록에 포함하지 않았다. Provider 호출 메타데이터는 [trace](p5-generalized-search-uat-trace-2026-11-13.jsonl)에 남겼다.

전체 `tests_unit`은 103개 통과, 1개 건너뛰었다. 건너뛴 변환기 통합시험은 설치된 Pandoc·LibreOffice 경로를 지정해 따로 실행했고, 샌드박스의 임시 폴더 실패 후 샌드박스 밖에서 내보내기 시험 3개가 통과했다. 실제 생성 호출은 6회, 별도 웹 검색 호출은 1회였고 Provider가 보고한 합계는 입력 38,484·출력 3,179·총 41,663토큰이다. 입력 계수와 청구액은 이 합계에 포함하지 않는다.

자동 구분 모드에서 검색이 꺼진 후속 질문을 모델이 문서 작성으로 잘못 라우팅하여 불필요한 문서 후보를 만든 사례가 관찰됐다. 검색 자체는 실행되지 않았다. 이 자동 라우팅 오분류는 이번 검색 변경의 해결 범위 밖으로 남긴다. 모델이 분류한 고정 어휘에서 표현할 수 없는 질의는 사용자가 공개 검색어를 직접 지정해야 하며, 현재 구현은 단일 프로세스 합성 저장소 기준이다. 팀 인증·권한·공유 저장소 및 다중 프로세스 통합 검증은 진행하지 않았다. 검색 Provider에 일반화 문자열만 넘긴 사실은 검증했지만, Provider 내부 검색 엔진의 실제 재구성 질의까지는 관찰하지 못했다.
