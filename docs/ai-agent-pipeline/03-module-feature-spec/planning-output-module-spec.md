## 처리·상태·예외

03은 CK에 대한 설명·수정 제안만 제공하며 CK 변경 Artifact·도구·승인 경로는 제공하지 않습니다(GD-042). CK 변경은 사용자가 02에서 직접 수행하고 해당 owner가 대상·권한·기준 revision을 검증합니다. 충돌 시 자동 병합·덮어쓰기하지 않고 편집안을 보존합니다. 세부 하위 필드의 독립 revision은 발명하지 않습니다.

04는 실행 시작 시 실제 허용된 입력을 고정합니다. 생성 중 자료 변경은 현재 결과에 혼합하지 않고 후속 비교에 반영합니다. 미등록 세션 자료는 출처와 세션 귀속을 유지하며 정본에 승격하지 않습니다. 불충분한 자료는 결손을 기록하고 가능한 결과만 작성합니다. 생성 후보 → 사용자 검토 → 새 문서 저장 → 확인/미확인의 논리 상태를 갖습니다. 직접 편집은 같은 문서의 revision 검증을 거치며 전체 재생성은 별도 후보와 새 문서 저장입니다.

읽기·권한·변환 실패, 원본 삭제, 중단 및 동시 편집/삭제를 구분합니다. 동일 쓰기가 미확인이면 조회로 확인하고 자동 재전송하지 않습니다. 프로젝트 삭제 후 늦은 결과를 반영하지 않으며 Chat 삭제 시 독립 프로젝트 문서를 일괄 삭제하지 않습니다. 삭제·생성 경합, 취소 및 실제 원자성은 공통 owner와 확인합니다.

## 검증 기준과 OPEN

다중 후보 중 승인된 CK만 반영; stale 후보 거부; 명시 선택한 DRAFT/세션 자료의 상태·출처 보존; 생성 시작 스냅샷 고정; 미제공 수치 날조 방지; 참조한 자료만 변경 감지; 기존 문서 선택 참조 전체 재생성은 새 ID; 기존 편집 보존; 네 형식 출력과 03 두 형식의 분리; 권한 상실·결과 미확인·프로젝트 삭제 후 늦은 결과 차단을 검증해야 합니다. 이는 인수 기대값이며 실행된 테스트가 아닙니다.

PRODUCT_OPEN: GD-035·038 승인 및 GD-037 저장 안내의 구체 화면과 추가 위임 범위, 컨텍스트 선택 UX. EXACT_OPEN: 버전 해상도·Markdown 지원 문법·편집 동시성, 스냅샷/manifest 표현 및 보존, staleness 의미, port/API·인증·멱등성·상태·에러, 변환 엔진·표현, 삭제 경합·물리 보존. UPSTREAM_BLOCKED: C-01~03 실제 권한·데이터/버전 포트·조건부 쓰기·삭제·결과 조회·Provider 지원. 구현 및 통합시험 NOT_RUN.

GD-035에 따라 AI의 기존 문서 수정·삭제 도구는 대상과 내용을 확인한 UI 최종 승인에 결박합니다. 승인한 대상·내용·기준 revision을 실행 직전에 검증하고 승인에 해당하지 않는 변경이나 충돌이 있으면 보류합니다. Chat 요청·모델 도구 호출은 승인 증거가 아니며, 수정·삭제 결과 미확인 시 조회만 수행합니다.

GD-038에 따라 04 문서 삭제는 대상·내용 확인과 최종 승인 후 실행하며 사용자 휴지통·복구 기능은 제공하지 않습니다. 물리 보존·백업 정책 및 삭제 완료 확인은 공동 계약입니다.

GD-036에 따라 생성·편집·저장의 본문은 Markdown 문자열입니다. 04 출력은 저장된 같은 본문을 기준으로 네 형식으로 변환하며 고정 목차는 강제하지 않습니다. GD-037에 따라 미저장 내용의 출력을 원하면 먼저 저장하도록 안내하고 내보내기에서 자동 저장하지 않습니다. 지원 문법·변환기·파일별 의미 보존과 오류 처리는 구현·검증 후속입니다.

GD-039에 따라 저장 문서의 manifest에는 실제 입력의 출처·상태·revision 등 메타데이터를 보존하되 자료 원본 사본을 보관하지 않습니다. 생성 중 입력은 Q7에 따라 고정하며, 임시 원본의 보관 위치·수명·폐기는 공동/물리 계약입니다. 삭제되거나 접근 불가한 원본은 복원하지 않고 비교 불가로 구분합니다.

GD-040에 따라 04 문서 생성의 초기 모델은 OpenAI `gpt-6-luna`입니다. 기존 03 대화·압축 모델의 선택과는 별개의 결정입니다. 04 호출 프로필·입력/출력 한도·실제 인증·계정 지원 및 오류 처리는 후속이며 선택 자체를 실호출 증거로 취급하지 않습니다.

**GD 보존:** 개별 Chat 삭제는 GD-034의 실행 종료/출력 차단 조건을 따르고, 이미 승인·전송된 프로젝트 저장 결과는 GD-032에 따라 별도로 확인합니다. 04 저장 문서는 프로젝트 귀속으로 유지합니다. 프로젝트 삭제는 GD-020·026에 따라 늦은 반영을 차단합니다. 실행 중 이미 획득한 참조의 권한 상실과 후속 요청의 재사용은 GD-015·016을 구분합니다. 실제 교차 owner 보장은 UPSTREAM_BLOCKED입니다.
