## 처리·상태·예외

03은 CK에 대한 설명·수정 제안만 제공하며 CK 변경 Artifact·도구·승인 경로는 제공하지 않습니다(GD-042). CK 변경은 사용자가 02에서 직접 수행하고 해당 owner가 대상·권한·기준 revision을 검증합니다. 충돌 시 자동 병합·덮어쓰기하지 않고 편집안을 보존합니다. 세부 하위 필드의 독립 revision은 발명하지 않습니다.

04는 실행 시작 시 실제 허용된 입력을 고정합니다. 생성 중 자료 변경은 현재 결과에 혼합하지 않고 후속 비교에 반영합니다. 미등록 세션 자료는 출처와 세션 귀속을 유지하며 정본에 승격하지 않습니다. 불충분한 자료는 결손을 기록하고 가능한 결과만 작성합니다. 생성 후보 → 사용자 검토 → 새 문서 저장 → 확인/미확인의 논리 상태를 갖습니다. 직접 편집은 같은 문서의 revision 검증을 거치며 전체 재생성은 별도 후보와 새 문서 저장입니다.

읽기·권한·변환 실패, 원본 삭제, 중단 및 동시 편집/삭제를 구분합니다. 동일 쓰기가 미확인이면 조회로 확인하고 자동 재전송하지 않습니다. 프로젝트 삭제 후 늦은 결과를 반영하지 않으며 단일 Chat 삭제 기능은 제공하지 않습니다. 문서 휴지통은 Chat·업무·원본 자료를 연쇄 삭제하지 않습니다. 삭제·생성 경합, 취소 및 실제 원자성은 공통 owner와 확인합니다.

## 검증 기준과 OPEN

AI의 CK 변경 경로 없음; 사용자가 직접 저장한 CK는 미작성/작성됨이고 저장 가설은 사실 확정이 아님; 명시 대화/편집안 출처 보존; 생성 시작 입력 고정; 미제공 수치 날조 방지; 참조한 자료만 변경 감지; 기존 자유형 전체 재생성은 새 ID; 새 항목 후보는 편집안 적용 뒤 별도 저장; 기존 편집 보존; 문서 네 형식과 CK+모든 기록의 두 형식 분리; 권한 상실·결과 미확인·문서 삭제/복구 경합을 검증합니다. 상세 인수는 AX-AC-001~062를 따르며 모두 NOT_RUN입니다.

제품 범위는 v0.3-R1과 D-MVP-001~014를 따릅니다. GD-035는 AI 도구 범위의 과거 기록이고 GD-038은 문서 휴지통 결정으로 대체됐습니다. EXACT_OPEN: 버전·Markdown 지원 문법·편집 동시성, 실행 중 입력/manifest 수명, staleness 판정, API·인증·멱등성·상태·에러, 변환 품질, 삭제/복구 경합·DB+첨부 백업 일관성과 복원 검증. 기존 C-01~03의 권한·자료·조건부 쓰기·결과 조회·Provider 포트는 통합 코드와 대조해 갱신할 설계 계약입니다. 신규 설계/구현·통합시험은 미완료입니다.

GD-035의 AI 기존 문서 수정·삭제 도구는 후속 P5에서 제외됐습니다. 이번 D-MVP-001은 새 템플릿 항목의 후보 적용만 확장하며 직접 쓰기/삭제 도구를 부활시키지 않습니다. 사용자의 문서 저장·휴지통 이동·복구는 대상·내용·권한·기준 revision·수명을 검증하고 충돌/미확인 시 자동 덮어쓰기나 재전송을 하지 않습니다.

D-MVP-004가 GD-038을 대체하여 일반/템플릿 문서에 사용자 휴지통·복구를 제공합니다. 같은 식별자·본문/임시 작성·검토·메시지/할 일 연결을 보존하고 삭제 전 후보를 복구 뒤 자동 적용하지 않습니다. P0 영구 삭제 UI는 추가하지 않습니다. 물리 보존·백업 정책과 실제 복원은 G-S/G-D 및 AX-AC-057의 검증 대상입니다.

GD-036에 따라 생성·편집·저장의 본문은 Markdown 문자열입니다. 04 출력은 저장된 같은 본문을 기준으로 네 형식으로 변환하며 고정 목차는 강제하지 않습니다. GD-037에 따라 미저장 내용의 출력을 원하면 먼저 저장하도록 안내하고 내보내기에서 자동 저장하지 않습니다. 지원 문법·변환기·파일별 의미 보존과 오류 처리는 구현·검증 후속입니다. 새 템플릿 출력은 문서 전체 항목의 미저장 변경을 확인하고, 필요한 저장이 모두 성공해야 일관된 저장본으로 진행합니다. 일부 실패 시 출력은 보류하며 성공한 저장과 미저장 입력을 보존합니다.

GD-039에 따라 저장 문서의 manifest에는 실제 입력의 출처·상태·revision 등 메타데이터를 보존하되 자료 원본 사본을 보관하지 않습니다. 생성 중 입력은 Q7에 따라 고정하며, 임시 원본의 보관 위치·수명·폐기는 공동/물리 계약입니다. 삭제되거나 접근 불가한 원본은 복원하지 않고 비교 불가로 구분합니다.

GD-040에 따라 04 문서 생성의 초기 모델은 OpenAI `gpt-6-luna`입니다. 기존 03 대화·압축 모델의 선택과는 별개의 결정입니다. 04 호출 프로필·입력/출력 한도·실제 인증·계정 지원 및 오류 처리는 후속이며 선택 자체를 실호출 증거로 취급하지 않습니다.
