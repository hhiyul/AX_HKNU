## 5. 세 정합 사항 종결 대장

OPEN 식별자는 추적을 위해 유지하며 아래 항목은 모두 CLOSED다. 종결은 제품 범위 결정의 완료이고 구현/시험 통과가 아니다. 기존 백엔드 설계의 두 상태·다중 record와 README의 전체 백업 미구현, 첨부의 별도 파일 보관을 대조한 뒤 사용자가 선택했다.

세 항목에 대한 추가 사용자 질문은 없다. v0.3-R1의 교차 점검 결과와 후속 설계 조건은 [정합 점검 기록](ax-studio-mvp-consistency-review-2026-11-23.md)에 있다. D-MVP-006~011은 합의에서 도출한 기본안으로 계속 구분하며, 명시 채택으로 소급 표기하지 않는다. 후속 설계가 사용자 의미를 바꾸려면 변경 근거와 영향을 기록한다.

## 6. 변경 관리

변경 기록은 변경 이유, 근거, 영향을 받는 AX-RQ/AX-AC, 폐기·대체한 이전 결정, 검토 상태를 함께 남긴다. 기준선 확정 뒤 발견한 코드 제약을 제품 요구의 자동 변경으로 처리하지 않는다. HandOff는 당시 이관 스냅샷으로 보존하며 소급 수정하지 않는다.
