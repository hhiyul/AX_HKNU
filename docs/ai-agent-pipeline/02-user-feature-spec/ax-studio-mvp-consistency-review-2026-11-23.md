# AX Studio MVP v0.3-R1 — 사용자 명세 정합 점검

작성일: 2026-11-23. 대상: [사용자 기능명세](ax-studio-user-feature-spec-v0.3.md), [결정 기록](ax-studio-mvp-decisions-v0.3.md), [인수 추적표](ax-studio-mvp-acceptance-v0.3.md).

검토 기준은 문서 커밋 `2b61e2b`와 통합 구현 `a4f3af7`, 이번 후속 정합 질문의 사용자 선택 `1A / 2A / 3A`다. 새 기능 구현·런타임 시험·사용자 인수 결과를 기록하는 문서가 아니다.

## 1. 판정과 적용 범위

**OPEN-MVP-01~03은 모두 CLOSED다.** 사용자 기능명세와 인수 조건을 v0.3-R1로 함께 개정했으며, 검토한 현재 문서 세트에서 시스템 설계 진입 전에 추가 사용자 선택이 필요한 제품 모순은 발견하지 않았다. 다음 단계는 G-S 시스템 설계다.

D-MVP-006~011은 앞선 맥락에서 도출한 작성 기본안이라는 표시를 유지한다. 이번 세 선택을 모든 기본안의 개별 승인으로 확대하지 않는다. 앞으로 설계 제약이 사용자 의미를 바꾸는 경우에만 영향받는 요구·인수·결정을 함께 개정한다.

기존 v0.2의 세부 CK 평가·자유 Chat·검색/자료 제외 규칙은 유지하고, 대체된 CK 초안/확정·단일 기록장 흐름은 명확한 이력 표시와 함께 보존했다. 과거 문서에 남은 해당 표현은 현행 요구로 다시 적용하지 않는다. HandOff는 당시 인계 자료로 보존한다.

## 5. 문서 검사와 실행 검증의 구분

정적 검사 결과는 이번 변경 파일의 UTF-8, 링크, 식별자, 14개 기능의 8항목 형식, 45개 요구와 62개 인수 사례의 연결, 템플릿 필수 항목 수와 변경 범위를 기준으로 기록한다.

- 정적 검사: 변경 Markdown 11개(추적 파일 10개·신규 점검 보고서 1개)의 UTF-8 엄격 디코딩·대체 문자 부재·상대 링크 존재를 확인했다. 14개 기능 각각 8개 작성 항목, AX-RQ-001~045와 AX-AC-001~062의 중복/누락 없음, 전체 45개 요구의 인수 연결, 참조 ID 범위, 현행 명세/결정/인수/점검 표의 열 수, 두 템플릿 8개 항목과 필수 6/8을 확인했다. 오류 0건, `git diff --check` 통과.
- 실행 검증: AX-AC-001~062 모두 NOT_RUN. 실제 AI/DB·변환·권한·동시성·백업/복구는 실행하지 않았다.
- 변경 범위: 사용자/보조/연결 문서만 수정. 애플리케이션 코드·데이터·HandOff 변경 없음. 커밋/푸시는 수행하지 않음.

운영 복구를 포함한 P0 인수는 구현 후 해당 환경에서 증거를 남겨야 한다. 이 문서의 ‘정합 종결’은 그 검증을 생략하거나 완료로 바꾸지 않는다.
