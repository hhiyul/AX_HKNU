# AX Studio MVP v0.3 — 요구사항·인수 추적표

작성일: 2026-11-23. 대상: [사용자 기능명세 v0.3](ax-studio-user-feature-spec-v0.3.md), [결정·변경 기록](ax-studio-mvp-decisions-v0.3.md).

**모든 AX-AC는 설계된 검증 사례이며 현재 NOT_RUN이다.** 아래 통과 조건은 실제 통과 결과가 아니다. 기존 통합 코드의 시험 성적은 신규 항목형 문서·할 일·휴지통의 인수를 대신하지 않는다. AX-RQ-001~042를 모두 연결한다. 여러 반례가 있는 행은 각 반례를 각각 실행해야 행이 통과한다.

## 2. 공통 검증 준비

- 서로 다른 두 계정, 브랜드 없는 프로젝트 및 두 브랜드의 여러 프로젝트, 기존 CK/record/자유형 문서/첨부/Chat의 보존 비교 자료를 준비한다.
- 펀딩·사업계획 각각 신규 문서를 만들고, 한 유형에 같은 제목의 문서도 둘 이상 만들어 이름 대신 식별자로 연결하는지 확인한다.
- 후보 생성 이후 편집, 다른 항목 이동, 다른 탭 저장, 문서 삭제 후 복구, 프로젝트 휴지통, 계정 변경, 저장 응답 유실을 재현한다.
- 실제 비용을 포함한 Provider 시험은 별도 실행 범위를 기록한다. 비밀키·민감 원문을 증거 파일에 넣지 않는다. 이번 명세 수정은 실호출을 실행하지 않는다.
- 각 결과에는 요구/사례 ID, 코드·명세 버전, 환경, 실행 시각, 관찰 결과, 증거 위치, 실패/미검증 이유를 남긴다. 사용자 화면의 성공 표시와 DB 재조회·실제 전달 결과를 함께 확인한다.
- 날짜 예시는 검증용이다. 오늘/기한 지남 시험은 화면에 표시한 시간대의 날짜 경계에서도 수행한다. 초기 사용자 명세의 시간대 기본안은 Asia/Seoul이다.
