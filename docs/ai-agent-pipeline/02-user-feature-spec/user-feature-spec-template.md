**작성 원칙**

- 아래 대괄호는 실제 내용으로 교체합니다. 적용되지 않는 항목도 삭제하지 않고 `해당 없음 — 사유`로 남깁니다.
- 합의한 내용과 `미정`, `공동 확인`, `모듈 설계 후속`을 구분합니다. 미정 값을 임의 값·0·완료 상태로 채우지 않습니다.
- 사용자 기능의 입력·출력·논리 데이터·상태 의미는 이 단계에서 명확히 씁니다. 실제 API 키·DB 컬럼·내부 클래스는 후속 설계와 연결합니다.
- 이미 합의한 구체적 제약은 그대로 기록합니다. 예를 들어 브라우저 인메모리라는 제약이 있으면 보관 수명과 복귀 범위까지 반영합니다.
- 식별자 `SC-01`, `IN-01`, `OUT-01`, `EX-01`, `ST-01`은 문서 안에서 흐름을 연결하기 위한 표기입니다. API·DB 이름을 확정하는 의미는 아닙니다.

사용자에게 보이는 결과와 다음 선택이 달라지는 대표 예외를 적습니다. 같은 원칙으로 처리되는 내부 실패 원인을 모두 별도 시나리오로 늘리지 않습니다.

| 예외 ID·발생 상황 | 발생한 시나리오·단계 | 사용자에게 안내·제공할 결과 | 유지·변경할 데이터·상태 | 사용자의 다음 선택 |
| --- | --- | --- | --- | --- |
| EX-01 [대표 예외] | [SC-01의 단계] | [실패·부분 결과·보류·미확인과 이유·영향] | [7절 데이터 / 8절 상태의 유지·변경] | [자료 보완·범위 조정·재요청 등 합의한 선택] |
| EX-02 [다른 사용자 결과가 필요한 예외] | [연계 단계] | [안내·가능한 부분 작업·보류 판단] | [변경되지 않는 내용도 명시] | [이어갈 수 있는 기능 / 종료] |

기능에 해당하는 권한·대상 불가, 자료 누락·처리 불가, 사용자 중단, 저장 보류·결과 미확인을 검토합니다. 새 사용자 선택이 필요한 경우에만 미정으로 올리고, 기술적 오류 코드·재시도 구현은 후속 설계와 연결합니다.

## 8. 상태 전이

### 8.1 상태 대상과 의미

| 상태 대상 | 사용하는 상태와 의미 | 정의·근거 |
| --- | --- | --- |
| [기능이 영향을 주는 대상] | [이 기능에서 실제 사용하는 상태만 나열·정의] | [기존 공통 정의·D-UF / 미정이면 추적 항목] |
| [구분이 필요한 다른 대상] | [앞 대상과 혼동하면 안 되는 상태] | [정의·근거 / 해당 없음과 사유] |

저장된 기획의 `UNSET / DRAFT / DECIDED`, 내부 평가, 실행 진행, 미저장 편집·임시 보관은 서로 다른 대상입니다. 해당 기능에 필요한 상태만 쓰고, 기존 상태를 임의로 추가·변경하지 않습니다.

### 8.2 전이·유지 규칙

| 전이 ID·대상 | 현재 상태 | 사용자 행동·발생 사건 | 필요한 선택·검증 조건 | 이후 상태 | 결과 확정 시점 | 예외 연계 |
| --- | --- | --- | --- | --- | --- | --- |
| ST-01 [대상] | [상태] | [SC 단계·사건] | [사용자 선택·권한·검증 등 해당 조건] | [변경 상태 또는 유지] | [사용자에게 결과를 확정해 보여줄 시점] | [EX / 보류 시 유지 상태] |
| ST-02 [유지할 대상] | [상태] | [조회·설명·편집·취소 등 관련 사건] | [유지되는 조건] | [유지] | [변경하지 않았음을 확인할 기준] | [EX / 해당 없음과 사유] |

상태를 변경하지 않는 기능도 유지되는 대상을 적습니다. AI 응답 완료를 업무 저장 성공으로, 내부 평가 완료를 사용자 확정으로, 임시 보관을 초안 저장으로 표시하지 않습니다. 전이 구현·저장 구조는 후속 설계에서 이 규칙과 연결합니다.

### 8.3 작성 완료 점검

- [ ] 1~8절이 모두 작성됐거나 해당 없음의 이유가 명시되어 있다.
- [ ] 시나리오의 입력·출력·예외·데이터·상태 규칙이 서로 연결된다.
- [ ] 사용자가 어떤 결과를 확인하고 다음에 무엇을 선택할지 설명할 수 있다.
- [ ] 값의 출처·자료형·단위·필수 조건과 보관 범위를 구분했다.
- [ ] 저장·확정·내부 평가·실행·임시 보관의 의미를 혼동하지 않았다.
- [ ] 기존 결정·검토 사례를 연결했고 미정·공동 확인·모듈 후속을 확정처럼 쓰지 않았다.
