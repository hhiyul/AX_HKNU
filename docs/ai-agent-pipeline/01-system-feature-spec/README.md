# 시스템 기능명세

전체 시스템이 제공할 기능과 범위를 정의하는 상위 명세를 관리합니다.

**현재 상태: 기술 기반·AI 연결 경계 사용자 확인 / 상세 시스템 기능명세 팀원 작성 대기.** 아래는 2026-11-06에 확인한 최소 기반이며 전체 시스템 기능·API가 제공됐다는 뜻은 아닙니다.

## 확인한 최소 기반 — 2026-11-06

| 영역 | 사용자 확인·현재 소스 | 명세 적용 경계 |
| --- | --- | --- |
| 화면 | React + Vite. `front/package.json`에서도 두 도구 확인 | 실제 Chat 화면·승인·결과 표시 계약은 프런트와 연결 |
| AI 백엔드 | Python. 이번 사용자 선택으로 구현·단위시험 기준은 **3.11** | 현재 Docker/requirements 생성 기준과 일치. 설치·실행·호환 검증 NOT_RUN |
| 진입 | Spring Gateway. 현재 `/api/**` 접두사를 제거해 FastAPI에 전달 | 기본 포트는 프런트 80 → Gateway 8080 → Python 8000. 현재 `permitAll`은 사용자 인증·자원 권한 제공을 뜻하지 않음 |
| 데이터 | MongoDB 사용. 사용자가 `MONGO_DETAILS` 환경변수로 DB에 연결된 상태임을 확인 | 이번 세션에서는 값·연결 문자열을 열람하지 않았고 DB 연결 검증 NOT_RUN. AI 기능에 필요한 데이터 API의 제공 여부와 구분 |
| AI의 공통 데이터 접근 | **팀원이 제공하는 API를 Python 어댑터로 호출** | 프로젝트·브랜드·CK·추가 기록·소유/권한·원문·세션 저장/조회·요청 결과 확인을 공통 담당과 연결. AI 모듈의 MongoDB 직접 접근을 기본 구현으로 채택하지 않음 |

모듈 경계는 `AI 파이프라인 → Python 공통 API 어댑터 → 팀원 API → 공통 데이터`입니다. API가 같은 Python 프로세스에 있는지, 별도 서비스인지, 어느 경로·인증 방식으로 제공되는지는 아직 미정입니다. 이 경계가 서비스를 추가하거나 Gateway에 업무 로직을 배치한다는 결정은 아닙니다.

다음에 필요한 제공물은 API별 **호출 경로·메서드, 인증 주체 전달, 입력/응답 필드, 조회 범위와 버전, 오류, 쓰기 요청 식별·종료/반영 결과**입니다. 실제 제공 문서와 버전은 확인 후 연결합니다. MongoDB 연결 상태만으로 이 계약이 이미 제공됐다고 표시하지 않습니다.

## 작성 시 정리할 내용

- 시스템의 목적과 해결할 문제
- 시스템이 제공하는 기능과 범위
- 시스템에 참여하는 사용자와 외부 시스템
- AI 에이전트 파이프라인이 담당할 부분과 다른 시스템 구성요소와의 관계
- 사용자 기능명세에서 구체화해야 할 요구사항과 제약

위 항목은 향후 문서를 정리하기 위한 안내이며, 실제 기능은 팀원의 명세를 기준으로 확인합니다. 원본이 다른 경로에서 관리된다면 원본 위치와 적용 버전을 연결하여 중복된 기준이 생기지 않게 합니다.
